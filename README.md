# Proyecto-Generador-de-logs-Crudos-Masivos-para-Puerto-Coquimbo
proyecto universitario para modelar un frente de atraque con fajas transportadoras, dos grúas móviles, una báscula de acceso vehicular y un patio con contenedores reefer conectados a la red eléctrica del terminal. Con el objetivo simular el comportamiento físico de ese entorno
